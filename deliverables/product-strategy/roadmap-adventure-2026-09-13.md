## 1. 当前指标表现（来源：数析）

如实状态：**冒险模块当前零埋点，原设计 8 个趣味指标 0/8 可完整采集**（数析 §2 评审结论）。其中 4 个（重玩、重试、尝试次数、时长）补事件后即可落地；2 个（世界完成率、D1/D7）需 N=1 口径重写；1 个（符文）依赖 V2 实现；1 个（主观一句话）缺 UI 入口。因此：

- **本季度不存在"当前值"**，所有阶段门引用的阈值是"假设 + 触发复查"而非"达标考核"；
- **P0 期北极星 WQAS 只记基线、不设目标**（数析 §1.1）；
- 度量节奏：M1 起每周末 `buildExport()` 导出 telemetry JSON 人工复盘（无后端下的现实做法，数析 §6）。

**北极星定义（WQAS，周冒险有效会话数）**：一个自然周内，"主动进入冒险模块，且完成至少 1 个章节节点推进（V1）或至少 1 次语言之门提交（V2）"的会话数。N=1 口径：分母是事件数（会话/门/章节），不是用户数；回访类指标退化为二值记录 + 纵向时间序列（本周 vs 上周），不做"率"的跨用户解释。稳定期目标 ≥3/周为**纯假设**（数析 §1.1），何时从基线切换为考核目标待积累 4–8 周数据后由数析建议（PRD 待确认 Q5）。

## 2. 用户反馈摘要（来源：瑞思）

前置事实：两份 UX 方案主体已落地，痛点按"已修复 + 残留"重排。

**核心断点（循环的"漏"）：**

- **H1 · 读（地基）**：无 AI 时历史/离线章节拿不到逐句译文，"生成译文"按钮直接报"请先配置 AI"——A1 用户"读"这个动作的前提被绑死在 AI 配置上（`AdventurePlayPage.tsx:661-664, :1163-1168`）。
- **H2 · 选（峰值）**：自动预加载期间所有选项与自定义输入整体禁用，读完正文动机最高的瞬间被迫等转圈（`:1232, :1235`）。
- **H3 · 选（信任）**：自定义行动在离线回退时被静默丢弃，故事走预置分支只留一行小字——"我写的没用"的隐性感知侵蚀"选择有意义"这个卖点本身（`:909-916`）。

**机会点（O1–O5，各一句话）：**

| # | 机会 | 一句话 |
|---|---|---|
| O1 | 译文与 AI 解耦 | 离线包预置译文 + AI 章节落库译文 + 词典级兜底，让"读得懂"不依赖任何配置 |
| O2 | 预加载不阻塞 | 选项逐个就绪逐个解锁，预加载中可点击打断走实时生成 |
| O3 | 自定义行动诚实化 | 回退时点名"你写的『……』这次没能用上"，消灭静默丢弃 |
| O4 | 收词反馈仪式化 | 保存后词卡飞入星标 1.5s 动效 + toast"冒险积累 +N"，星标常显本章已收数 |
| O5 | 悬念回访钩子 | 章末一句下章预告存入节点，Hero 卡展示"上次：……"残片，进度改诚实口径"已读 N 章" |

## 3. 竞品动态（来源：竞析，对排期有影响的 3 条）

1. **薄荷阅读验证了成人叙事付费市场（年卡 158–298 元、小红书自发刷屏），但它"只读不写"**——市场被验证、"写"的需求裸露在外，这是我们的窗口期；同时其背后是百词斩的内容产能，**若其互动小说 SKU 扩充并下沉难度（T 威胁），窗口收窄**。排期含义：M1 手感验证不能无限推迟，Q4 内必须拿到结论。
2. **Duolingo 能量系统反感外溢**：2025 年中起免费体验"答错答对都扣能量"，成年用户吐槽加剧——"不惩罚学习者"从我们的红线变成有外部参照的定位资产。排期含义：M2 的 NPC 记忆（R8，唯一的无惩罚留存机制）值得按竞析 §6.3-2 的建议保持提前，不后移到 M3。
3. **大厂复制风险**：Duolingo Adventures 已在用 AI 生成场景迷你游戏，若加入"自己写句子推进"，我方唯一结构性空白（产出-剧情绑定 + 错误喜剧化，7 家竞品矩阵双空白）将被压缩。排期含义：M1 决策门的态度是"**先验证手感**"而非"先堆内容"——手感不成立则及早止损，手感成立则 Q1 用 R12 的 AI 关卡生成拉开内容供给速度，这正是对产能威胁的正面回应。

**M3 决策门（2027 Q1 内）：**
- 信号①：**AI 生成关卡可用率 >70%（假设，竞析 §6.3-3 生命线；无需手改即为可用）**——≤70% → **不扩世界**（R13 冻结），退回"手写种子内容 + 提示词调优"，一个月后复评；>70% → 放行 R13 两个世界。

## 5. 利益相关者沟通要点

单人自用产品没有外部干系人，"利益相关者"是开发者的三个角色视角。每次阶段评审按对应视角过一遍。

### 5.1 决策视角（该不该继续投时间，看哪些信号）

- **本季度的唯一赌注是 M1**：Q3 的 M0 是还债（循环漏 + 眼睛瞎），不创造新价值；Q4 的 M1 才回答"写句子推进剧情"这个唯一不可替代的差异化是否成立。
- **继续投的充分条件**（M1 门）：连玩 3 天不是任务 + 重试率 ≥70% + 重玩占比 ≥15%（后两条为假设口径）。三条都亮 → M2/M3 放行，全年投入约 30–38 个人日（假设值合计）是合理的。
- **止损信号**：重玩占比 <10% 或重试率 <50% → 改机制，预算上限再投 1 周；改完复测仍不达 → **承认假设不成立，冒险模块退回 V1 阅读工具定位，V2 全线冻结**。这比"再做一个世界试试"便宜得多。
- **外部时钟**：薄荷阅读 SKU 扩充与 Duolingo Adventures AI 化在压缩空白窗口——这是"Q4 内必须拿到 M1 结论"的紧迫性依据，不是"跳过 M0 直接上"的理由（信号污染的风险大于 1 周的时间成本）。

### 5.2 工程视角（技术风险与依赖）

- **R4 埋点是 M1 的硬前置**：没有 22 个事件，M1 的三个复盘信号（三档分布、错误后 30s 流失、重试率）全部不可见，手感验证等于白做。M0 内 R4 必须与 R1–R3 并行而非排尾。
- **R1 的离线兜底选型待定（PRD 待确认 Q1）**：预置译文包（质量好、有内容产能成本）vs 词典级整句兜底（本地、质量有限）vs 在线补齐（仍依赖 AI）。倾向"AI 章节落库译文 + 模板预置译文"为主、词典兜底为最后防线——**本周拍板，否则 M0 第 1 天就被卡住**。
- **R8 NPC 记忆依赖 M1 的 GateAttempt 历史**：R8 排在 M2 的前提是自用品在 M1 观察期攒够了 ≥3 次同 NPC 交互且带 errorTags 的记录；若 M1 观察期样本不足，R8 实现后无法当场验收，需预留"历史为空回退默认台词"的兜底验证路径。
- **R12 是全路线图最大工程不确定性**（5–10d，区间最宽）：JSON 契约扩展、三条红线硬约束写进提示词、可用率评估流程（PRD 待确认 Q6）三者耦合。建议在 M3 第 1 周先做一个 10 关的小样本可用率试跑，再决定 R13 排期。
- **零网络、零第三方 SDK、localStorage 上限告警**是 R4/R12 共同的架构约束（复用 grammarTelemetry 的 stats 模式），任何引入外部依赖的方案在评审时直接拒绝。

### 5.3 体验设计视角（红线守护清单）

每阶段评审时逐条核对 PRD §8 Non-goals 十条，重点映射到阶段：

| 阶段 | 高风险红线 | 核对点 |
|---|---|---|
| M0 | #8 第三方 SDK / #10 不写句子过关 | R4 埋点实现是否零网络请求；R3 的方案是否仍保留"写了就有回应"的诚实性 |
| M1 | #1 streak / #3 失败重来 / #10 输出替代 | 三档判定是否任何路径都绕开"不写句子过关"；near/misread 反馈是否无惩罚措辞（红线 2 脚本校验：无 wrong/incorrect） |
| M2 | #1 streak / #4 数值膨胀 / #6 推送催促 | R8 NPC 记忆是否滑向"连续天数"式计数；R7 悬念钩子是否只走剧情残片、不引入任何通知；R6 进度改"已读 N 章"后是否还有失真的百分数残留 |
| M3 | #5 低幼化 / #7 抽卡随机奖励 / #10 | AI 生成内容的文风是否在"温和都市奇幻"基调内；R11 灯焰三态是否零数值惩罚；自由回应模式的判定兜底是否仍要求写句子 |
| M4 | #2 排行榜 / #9 付费点 | 回声墙周报是否引入任何形式的社会比较或数值排名 |

通用规则：任何阶段里出现"为了趣味/留存可以破例一次"的提案，对照红线直接拒绝，不进排期（PRD §8 已写入评审规则）。

## 6. 与 PRD §9 建议稿的差异说明

| # | 调整 | 理由 |
|---|---|---|
| 1 | **R14（主观一句话，1d）从 M3 提前到 M1** | 数析 §6 把"主观一句话 + 会话时长"列为 P0 验证期的第三信号（定性校准）；且填报率本身是情感投入度的代理指标（数析 §2-8）。验证期缺了它，M1 复盘只有行为数据没有定性对照。成本 1d，收益是整个 M1 的复盘质量。 |
| 2 | **R11（符文图鉴 + 灯焰 + 母语回声，5d）从 M2 后移到 M3 前段** | ① PRD §6 需求池本身把 R11 定为 P2，与 R6–R8（P1）不同级，§9 把它放进 M2 是建议稿的内部不一致；② M2 决策门（重玩占比、重试率）只依赖 R6–R8 的回流信号，R11 在场与否不改变判定；③ M2 保持 6–7d 的轻量体量，才能在 M1 门不通过时低成本掉头——背着 5d 的 R11 改机制，沉没成本会干扰止损判断。 |
| 3 | **M4 由"按需"改为门控进入** | PRD §9 的"按需"不满足可执行要求。现给出明确进入条件（M3 门通过 + WQAS 基线满 4–8 周 + 护栏无恶化）与退出标准（世界完成率 >60% 假设口径、D7 回访趋势），消除模糊节点。 |
| 4 | **M0 时长由"约 1 周"修正为约 2 周（9.5–14d 假设值）** | R1–R4 + R9 的人日估算下限合计 9.5d，单人按 5d/周计已接近 2 周，"1 周"只在全部走下限时成立。时间轴按 2 周排，避免 M1 被隐性地压进 10 月下旬才启动。 |
| 5 | **M1 决策门补充数析修正口径** | PRD §9 引用 GRAMMAR §11 的原始阈值（重玩 <10% 改机制），本版补齐数析的修正：重试率 ≥70%（由 >90% 下调）、重玩按"重玩会话占总会话 ≥15%"的 N=1 口径、平均尝试次数排除放弃样本。阈值数字不变的地方沿用原文，口径模糊处全部落到数析版本。 |

未调整的部分：M0–M4 的阶段划分与重排逻辑（先修漏装眼、再验证手感）、R9 顺手并入 M0、R8 提前到 M2（竞析 §6.3-2）、R12/R13 捆绑排期——均沿用 PRD §9，理由充分无需改动。
