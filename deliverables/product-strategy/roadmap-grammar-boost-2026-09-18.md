## 📌 TL;DR

1. 本次是**新增**：在已上线的 75 课 / 84 案 / 三关卡 / 复习页 / 日记 AI 批改 / 16 类埋点之上，加「趁热练」三档强化，补完课→次日 20h 的唯一空窗。
2. 排期：**W0 口径修复（≤1 人日）→ W1 = M1 最小闭环（6 人日）→ W2 = M2 AI 层（5 人日）→ W3 = M3 弱点驱动（3 人日）**；因果结论最早 W6–W8 才可读。
3. W0 的 3 项口径修复 + 关 3 埋点是**硬前置**：不做，后面所有对比都建在噪声上（北极星分子口径、mastered 双口径、弱点权重错位）。
4. 三道决策门可执行化：参与率 ≥30% 进 M2；档1 完成 ≥80% 且档3 进入 ≥25% 进 M3；配对差值 ≥+10pp 保留。
5. 最大风险不是"做不完"而是"读不懂"：n=1 + 20h 冷却使每组需 ≥8 课，M3 建设可开工、结论必须等样本；其次才是 CTA 让位与 AI 延迟。

- **R-B16 冲到第 7**：每档完成都触达（Reach 9）、Effort 仅 0.5，RICE 系统性偏好"高频低成本"。但**不提前到 M1**——M1 要保埋点纯净与最小闭环；改为**提到 M2 前段**（做完 R-B12 后立即做），理由是它给每档完成率补一个主观信号，Gate-2 需要。

## §6 利益相关者三视角沟通要点

**① 产品负责人版（战略 / 影响 / 拍板）**
- **战略对齐**：语法线已从"学完"走到"说得出"的瓶颈——practice 一次通过 20/20，同期无提示产出 0/9，课程全文 0 处 AI 调用。"趁热练"把动机峰值变现，且补的是**唯一**一个系统在说"今天到此为止"的空窗（`GrammarLessonPage.tsx:1969-1974`）。
- **业务影响（北极星）**：周有效输出句数与关 2 一次通过率；两项都依赖 W0 口径修复才可信。
- **需拍板 3 件**：**①** 结算页 CTA 让位是否削弱侦探转化（备选：首屏只放趁热练）；**②** n=1 是否接受方向性证据（直接决定 M3 的 3 人日是否值得）；**③** L2/3/5/6/8 档 3 出口（影响内容工作量与档3 完成率分母）。

**② 工程版（细节 / 时间线 / 依赖 / 验收）**
- **新增**：`grammarBoostService.ts`（档1/2 派生+判题）、`grammarBoostAiService.ts`（批改+变式+缓存）、`GrammarBoostPage.tsx`（档选择/进行/完成三态）、路由在 `App.tsx:172-176` 区段追加 `/grammar/boost/:lessonId`。
- **复用不要重写**：`grammarAmbushService.ts` 的 `pickClozeWord` / `shuffleTokens`（但 24 词正则在 `:154` 必须扩，即 R-B8）、`lessonService` 三关卡锁、`cardService.addSentence`、`grammarTelemetry` append-only 键空间与归档、`diaryService.ts:242-244` 的 prompt 抽 `GRAMMAR_CORRECTION_RULES` 共享常量。
- **硬指标**：逐题 8–10s 超时**不吃**默认 120000（`storage.ts:76`）；`grammarBoostsDone` 进 `knownAppDataKeys`（`storage.ts:153`）+ normalizer；埋点 **7 事件** = boost_offered / started / step_result / abandoned / completed / ai_result + grammar_reaudit_started；档位条渲染在卡片 `<Link>` 之外。
- **验收**：自用跑通 ≥8 课（含 1 课无案件、1 课已完课旧卡）；5 事件字段完整；键盘可达手测；断网与无 key 两种降级手测；单测覆盖 cloze 扩表与 70/90 阈值。

**③ 内容版（内容即产品）**
- **派生规范**：档①取 `contrast[].wrong/.correct` 前 4 条（与结算页 `contrast[4..]` 错开）+ `examples[]`/`dialogue[]`；档②取 `targetSentence`/`variants[].en`/`sceneSwings`/`practice[].answer`/`guided.arrange.tokens`/`recall`；档③取 `targetSentence`+`recall`+`variants`（3.1 条）。
- **cloze 词表 24→≥60**：覆盖批九–批十一关键词（could you / would like / give sb sth / finish / as…as / too…to / good at / buy for / Would you mind / enough / How often / How long does it take / Let me / Let's / How about）。
- **AI 审校纪律**：6 条校验（归一化对齐锚点 / 题面无答案原文 / 考点词白名单 / 长度与字符上限 / 题面无中文 / 干扰项不同形）→ 丢弃补位 → 补位不足减题；10 题小样 ≥8/10 过校验、人工判考点命中 ≥8/10；答案由确定性规则定，AI 只做措辞与解释。
- **5 课无案件**：维持"不配案"（`huntCases.ts` 头部决策⑤已记录），档 3 不追加"去挑战"出口。
