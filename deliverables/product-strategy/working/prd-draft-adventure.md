## 1. 产品目标

三个目标相互正交：分别对应"修漏"、"验证差异化"、"建立度量"，任何一个达成都不能替代另外两个。

**G1 · 补全核心循环的地基（修漏）**
核心循环「读 → 选 → 收词 → 回访」当前在"读"和"选"两个环节是漏的（瑞思 H1/H2/H3）。目标：让无 AI 配置的用户也能完成完整循环——读得懂（译文可及）、选得动（预加载不阻塞）、选了有用（自定义行动不被静默丢弃）。
衡量：H1/H2/H3 三个断点在代码与体验上消除；对应护栏指标（AI 生成失败率、译文缺失率）可见。

**G2 · 验证"写"对"看"的代差手感（差异化验证）**
V2 语言之门是 7 家竞品全部空白的结构性机会（竞析报告 §2 矩阵：语言产出要求 6/7 为零，错误喜剧化反馈无人做过）。目标：以最小代价（站台世界 8 关）验证"成人会为 NPC 的误读主动改句子"这一核心假设。
衡量（假设，触发复查用）：错误后立即重试率 ≥70%；平均每门尝试 1.5–2.5；误读后 30 秒流失率趋近 0。**P0 唯一验收：开发者自己连玩 3 天、每天 2 关，不觉得是任务。**

**G3 · 建立冒险模块的度量能力（埋点基建）**
当前冒险模块 0/8 趣味指标可采集（数析报告 §2），没有埋点，G2 的验证就没有眼睛。目标：落地 `adventureTelemetry.ts`（22 个事件），让 P0 验证期的三个信号（三档分布、错误后流失、重试率）可见。
衡量：P0 验证期每周末可导出 telemetry JSON 人工复盘；北极星 WQAS 可计算（P0 期只记录基线，不设目标）。

## 2. 用户故事

画像：成人、零基础起步（A1–A2）、桌面端一次 8–15 分钟、无"我要学好英语"的目标感、对被纠正敏感、反感低幼化（瑞思报告 §1）。

**S1 · 没配 AI 的晚上，我也想读懂这个故事**
我打开上次没读完的冒险。这一章是离线模板生成的，没有逐句译文。我点"生成译文"，它说"请先在设置中配置 AI"。我 A1 水平，没有译文我读不透，只能关掉。
→ 期望：译文是"读"的地基，不该绑在 AI 配置上。离线章节预置译文，历史缺译文章节有一键兜底。（对应 R1）

**S2 · 刚读到最精彩处，别让我等转圈**
我读完一章，正想知道"后来呢"，但所有选项按钮都是灰的——自动预加载在跑。我等了几秒，兴奋劲过去了。
→ 期望：选项就绪一个解锁一个；我也可以在预加载中直接点击，打断预加载走实时生成。（对应 R2）

**S3 · 我写的那句话，去哪了？**
我在自定义行动框里写了"我想先去桥那边看看"，点了提交。故事走了预置分支，和我的输入毫无关系，只有一行小字"已使用离线剧情续章"。我隐约觉得"我写的没用"，但说不清为什么。
→ 期望：离线回退时明确告诉我"你写的这次没能用上"，或改输入框占位文案事前说明。（对应 R3）

**S4 · 我说错一句话，故事真的误解了我（V2 手感验证场景）**
回声城门前，NPC 问我什么时候到的。我写 `I go to the park yesterday`——NPC 真的以为我**现在**要去公园，认真地给我指路。我笑了，然后把句子改成 `I went…`，NPC 说 "Ah, last night!"。我记住了 went，比任何讲解都牢。
→ 期望：三档判定 + 误读支线按 GRAMMAR_ADVENTURE_PLAN §2.3/§3 实现。（对应 R5）

**S5 · 第三次见到 Vera，她记得我**
Vera 说："上次你把 -s 忘了。可今天——'she goes'——完美。"这个产品里没有排行榜没有 streak，但有人记得我。我想回来。
→ 期望：NPC 记忆读 GateAttempt 历史的 errorTags 生成。（对应 R8）

## 3. 用户研究洞察（来源：瑞思报告）

**前置事实：两份 UX 方案已是代码现状。** ADVENTURE_UX_PLAN 的 P1–P8 主体已落地（Hero 继续卡 `AdventurePage.tsx:282-303`、一屏化阅读页 `AdventurePlayPage.tsx:1022-1151` 等），旧痛点清单应按"已修复 + 残留"核对。残留：P5 新形态（AI 推荐卡静默覆盖线索，`:179-183`）、P8（AI 生成中/失败反馈弱，`:428/:419`）。

**核心痛点（按对核心循环的伤害排序，瑞思报告 §3.2）：**

| 编号 | 痛点 | 击中环节 | 代码依据 |
|---|---|---|---|
| **H1** | 无 AI 时历史/离线章节拿不到逐句译文 | 读（地基） | `AdventurePlayPage.tsx:661-664, :1163-1168` |
| **H2** | 自动预加载期间选项整体禁用 | 选（峰值时刻） | `:1232, :1235` |
| **H3** | 自定义行动离线回退时被静默丢弃 | 选（信任） | `:909-916` |
| H4 | 收词保存反馈过轻 + 进度度量失真（`path.length*20`，5 章即 100%） | 收词/回访 | `:989, :1236`；`AdventurePage.tsx:141` |
| H5 | 无悬念回访钩子 + 句级进度不持久 | 回访 | 章末无预告；`:338` |
| H6 | AI 推荐卡静默覆盖用户线索 | 创建 | `AdventurePage.tsx:179-183` |
| H7 | AI 生成中/失败反馈弱 | 创建/续章 | `:428, :419` |

瑞思排序逻辑：**先保证"读得懂"，再保证"选得动、选了有用"，然后让"收获被看见"，最后修"想回来"**。前三个不修，核心循环是漏的——这直接决定了本 PRD 的 P0 范围。

**机会点（瑞思报告 §5）**：O1 译文与 AI 解耦、O2 预加载不阻塞、O3 自定义行动诚实化、O4 收词反馈仪式化、O5 悬念回访钩子。建议 O3/O4 与 V2 语言之门合并实施，避免重复改动动作坞。

**动机结构判断**：冒险是产品内唯一"有东西在等你"的模块（叙事动机）；六个真机制中悬念/收集/成长可见已成立，**即时因果与角色关系尚未成立**——正是 V2 语言之门与 NPC 记忆要补的。

## 4. 竞品对比（来源：竞析报告，文件 `working/competitive-research-adventure.md`）

**矩阵要点（7 家：Duolingo / LingQ / Beelinguapp / 薄荷阅读·爱阅读 / LingoDeer / EWA / Memrise）：**

1. **语言产出要求：6/7 为零**。唯一例外 Memrise 的 MemBot 自由对话也没有剧情后果。所有竞品的剧情都是"看"，没人强制"写"。
2. **错误反馈两极**：Duolingo 红叉+能量惩罚（错误=损失），阅读类产品没有错误概念（错误=不存在）。**把错误本身变成内容（NPC 误读支线）无人做过。**
3. **薄荷阅读验证了成人叙事付费市场**：2025 年起上线约十本英文互动小说（傲慢与偏见/呼啸山庄等），年卡 158–298 元，小红书自发刷屏——但它全程只读不写，"解决的是坚持不下来的问题，不是学不会的问题"。
4. 赛道三层分化：入口层（Duolingo/EWA/Memrise 游戏化）、输入层（LingQ/Beelinguapp/薄荷阅读 阅读浸泡）、教学层（LingoDeer 语法课）——**没有一家把叙事推进和强制语言产出缝合**。

**空白机会（竞析报告 §5，即我方 V2 的落点）：**

| 空白 | 依据 |
|---|---|
| "写"对"看"的代差 | 矩阵"语言产出要求"+"错误反馈方式"两行竞品同时为空白 |
| 错误即内容（误读支线→安全混乱→重玩点） | 对比 Duolingo 能量惩罚与阅读类回避错误 |
| NPC 记忆 = 无惩罚黏性 | 对标 streak 的情感功能，竞品无对应物 |
| 个性化 AI 剧情 vs 固定内容产能 | 薄荷阅读年产能约十本；我们"输入线索→生成只属于你的冒险" |
| 零基础成人的体面入口 | Duolingo 低幼化、LingQ 要 A2+、薄荷阅读锚定四六级 |

**竞品已交学费、必须避开**：streak 归零/修复付费、体力/能量、排行榜、核心闭环上免费锁（LingQ 20 词额度）、固定内容重资产、先上课后应用、低幼化（竞析报告 §6.2）。

**竞析的优先级建议（§6.3）**：P0 只验证误读支线手感；NPC 记忆提前到 P1；AI 关卡生成是生命线（P2 可用率 >70%）；若错误后重试率 <70%，优先改文案而非改判定。

## 5. 数据依据（来源：数析报告，文件 `working/metrics-framework-adventure.md`）

**北极星：周冒险有效会话数（WQAS, Weekly Qualified Adventure Sessions）**
定义：一个自然周内，"主动进入冒险模块，且完成至少 1 个章节节点推进（V1）或至少 1 次语言之门提交（V2）"的会话数。与全局北极星「周有效学习日」同构。目标（假设）：稳定期 ≥3/周；**P0 验证期不设目标，只记录基线**。

**指标树三层**：L1 结果（D1/D7 回访、路线完成率、主动重玩率、符文进度）；L2 过程（创建漏斗、语言之门三档分布、错误后立即重试率、会话时长、选项 vs 自定义占比、收词率）；L3 护栏（见下）。

**护栏指标（最高优先级，直接度量红线「不制造焦虑」）：**
- **错误后 30 秒流失率**（misread/near 后 30s 内退出会话）——"反馈是否伤人"的第一信号；
- **AI 生成失败率**（创建/续写/推荐三类分开统计）；
- 同一门连续 ≥3 次未 pass（挫败前置信号）；TTS 播放失败率。

**关键修正（数析对 GRAMMAR_ADVENTURE_PLAN §11 的评审结论）**：8 个趣味指标方向全对，但当前 **0/8 可完整采集**；错误后立即重试率目标从 >90% 下调至 ≥70%（<50% 触发文案复查）；重玩/完成率/D1D7 需改写为 N=1 口径（事件数为分母、纵向时间序列追踪）。

**埋点基建**：新建 `src/services/adventureTelemetry.ts`，复用 `grammarTelemetry.ts` 的纯本地模式（append-only、主键上限+归档键、JSON 导出），**22 个事件**（数析报告 §3 全表），不接任何第三方 SDK、不做 A/B 框架、不做实时看板。

## 6. 需求池

优先级判据：
- **P0** = 阻断核心循环（H1/H2/H3 不修，读→选是漏的）**或** 手感验证前置（没有埋点无法验证 G2；语言之门 P0 是所有差异化里最不可替代且技术风险最高的一环，竞析 §6.3-1）。
- **P1** = 循环的"回流"与"获得感"（决定循环转得久不久）+ 唯一无惩罚留存机制（NPC 记忆，竞析 §6.3-2 建议提前）+ 低成本信任修复。
- **P2** = 扩量与锦上添花，依赖 P0/P1 验证结论。

## 8. Non-goals（明确不做什么）

以下写入红线，评审时此类需求直接拒绝，不进入排期：

1. **streak 打卡及归零/修复机制**——目标置换、断签即流失，且对自用产品毫无意义（GRAMMAR_ADVENTURE_PLAN §1 反例清单、§12 红线 3；竞析 §3.1 Duolingo 教训）。
2. **排行榜 / 好友 PK / League**——自用工具无人可比，制造压力（§1 反例清单；竞析 §6.2）。
3. **体力 / 能量 / 限时关卡 / 失败重来**——违背 `Do not punish the learner.`（§12 红线 3；竞析 §3.1 能量系统争议）。
4. **经验值 / 等级条数值膨胀**——涨了不代表会了；成长可见用"昨天只能说我饿了，今天能说我昨晚在车站饿了"表达（§1）。
5. **低幼化美术与音效**——目标用户是成年初学者，要体面地学会（§6.3；竞析 §6.2）。
6. **推送通知 / 每日任务催促**——回访钩子只有悬念一个（§5 回访钩子原话"不做推送通知"）。
7. **抽卡式随机奖励**——被操纵感（§1 反例清单）。
8. **第三方分析 SDK / A/B 实验框架 / 实时看板**——违背本地优先与隐私原则，N=1 无意义（数析报告 §6"不做的事"）。
9. **核心闭环上锁 / 任何付费点**——本地免费自用，LingQ 20 词额度是反面教材（竞析 §3.2）。
10. **在语言之门允许"不写句子过关"的机制**——趣味不能替代输出（§12 红线 1）。

## 10. 待确认问题

1. **R1 的离线兜底方案选型**：词典级整句机翻（本地、质量有限）vs 预置离线译文包（质量好、内容产能成本）vs 一键在线补齐（仍依赖 AI）——三者成本/体验取舍需主理人拍板；倾向"AI 章节落库译文 + 模板预置译文"为主，词典兜底为最后防线。
2. **R3 的两种方案取舍**：事前改写输入框占位文案（零惊喜但零欺骗）vs 事后点名回显（保留输入乐趣但承认没听懂）。瑞思建议最小版做后者；是否与 V2 误读支线机制合并（进阶版）待定。
3. **M0 与原 P0 的先后**：重排意味着语言之门晚上线约 1 周。若主理人认为手感验证优先于一切，也可 M0 只做 R4 埋点、R1–R3 后置——但 H1 不修，无 AI 会话的验证样本会缺失（自用者恰恰可能不配 AI）。
4. **R8 NPC 记忆的触发门槛**："第三次见面"是设计直觉（§6.2），首次实现是按 NPC 维度还是按 errorTag 维度聚合历史，需开发时定。
5. **WQAS 稳定期目标 ≥3/周为纯假设**，何时从"记录基线"切换为"考核目标"需数析在积累 4–8 周数据后给建议。
6. **R12 可用率 >70% 的判定流程**：谁评、多少样本、误判（喜剧变冤案）如何分级——竞析已提示判定误判是最高技术风险（SWOT-W）。
7. **任务跟踪缺口**：本 PRD 对应的原任务 #4 在任务列表中不存在（仅有 #1 已完成、#2 阻塞），已新建任务 #3 跟踪本工作，请主理人知悉。
