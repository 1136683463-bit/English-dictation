## 口径说明（重要）

`g1final.ts` 是唯一权威口径，其定义：**课内词表不含 practice 自身的 tokens**。
若把题目自己的 tokens 算作「课内出现过」，D 层会恒为 0——那等于用题目自己的材料证明题目自己没问题，命题失去意义。

## 2026-09-20 内容修订脚本（D 层清零 + 108 课补 C 层新句位）

| 脚本 | 作用 |
|---|---|
| `cumulative.ts` | **累计词汇口径**下的 D 层检测（本课 + 此前所有课的教学材料） |
| `c-layer.ts` | 108 条 C 层新句的创作数据（含 promptZh / tokens / distractors / answer） |
| `inject.ts` | 校验四条红线后注入 `grammarLessons.ts`（含反例验证：注入 `zzzq` 会被拦下） |

**`inject.ts` 的四条校验**（任一不过就 exit 1，绝不写盘）：
1. 新句所有词 ∈ 累计词表
2. tokens 词集 == answer
3. distractors 不与答案词重复
4. 新句不在本课展示池中（否则退化成 B 层，白加）

**口径统一说明（重要）**：`g1final.ts` 与 `cumulative.ts` 现已统一到**累计口径**——
判断某词是否「教过」时，看的是**到本课为止**的全部教学材料，而不只是本课。
早期用「仅本课」口径会误报 32 道「本课没出现但前课教过」的复习题为缺陷（那是刻意设计）。

## 2026-09-20 第三轮脚本（重放题治理）

| 脚本 | 作用 |
|---|---|
| `replay-check.ts` | **检测「重放题」**：答案与看段同句 + 中文提示同译（治理前 94 道 → 现 0 道） |
| `cognitive-levels.ts` | 认知层级分级（识字级/变换级/组织级）+ 练段首题类型 + 复现题位置分布 |
| `grammar-gate.ts` | **语法合法性闸**：挡住 `am want an umbrella.` 这类病句（穷举替换的必要配套） |
| `replay-replacements.ts` | 94 条重放题的替换清单（含 4 条经确认的内容边界豁免） |

**为什么需要语法闸**：程序化穷举单词替换会产出形式合法但语法错误的结果。
前五道闸只查「词是否学过 / 句子是否重复」，不查「句子是否像英语」——
`am want an umbrella.` 能通过前五道闸，因为它每个词都学过、也没重复过。
