## 一、排期口径与前提

- **产能**：单人全栈，2~4h/天，每周按 5~6 个投入日计（留 1 天余量），周吞吐 ≈ 4~6 raw 人日。与 v1「M1 约 10 raw 人日 → 5~6 自然日」的实际节奏一致。
- **缓冲**：所有人日 ×1.5（v1 口径延续），每周日留半天只回归、不加功能。
- **v1 遗产盘点**：v1 M1 已落地 P0-1 引导卡 / P0-3 速通本徽标 / estimatedDays 新口径 / completedAt / learningTelemetry；v1 未交付的 P0-2 指令卡、P0-4 薄弱词下钻已并入 v2 P0-4 / P0-5，不重新论证。**v1 已上线的学习链路意味着用户学习行为已开始积累——复习峰值不是"将来时"，是"进行时"。**

## 五、裁剪建议（产能 <60%，即周吞吐 < 2.5 raw 人日时触发）

沿用 v1 经验：**宁砍激励类，保防守类**。

**保（防守四件套，任何情况下不动）**：
- **P0-1 埋点**——不埋则全盘无法验收，且仅 0.5~1 人日，性价比最高；
- **P0-2 队列过滤**——G1 核心，mastered 复刷是最确定的体验毒点；
- **P0-4 指令卡**——G2 核心 + v1 遗留主线，且是 P1-4 的依赖前置；
- **P1-4 积压预警**——唯一时间不可顺延项，砍掉等于放弃复习峰值防守。

**砍/顺延（按顺序）**：
1. **W4 整周冻结**：P1-3 导入预览（2.5 人日，P1 最大项，导入链路当前可用）、P1-5 死卡唤醒（需数据积累才有靶子，延一轮更准）、P1-7 遥测导出（✅ #4 已拍板前移 W2——若触发裁剪，则缩为最小 JSON 导出保留在 W2 尾部，1 人日内）；
2. **P1-6 降级**：IA 术语统一缩为「今日页查看词库改指 /units」单项（0.2 人日），全站改名延到下轮；
3. **P1-2 到期角标、P0-5 薄弱词下钻顺延一轮**（P0-5 是纯接线，若仅有半天余量优先捞回）；
4. **极限情况**：P0-3 返回路径缩为「完成页回来源页」最小集（0.5 人日），滚动位置记忆放弃；
5. **P2 全池本就冻结**，无需再砍；P2-2 里程碑激励即使产能恢复也建议等复盘数据支持后再做。

裁剪后最小闭环：P0-1 → P0-2 → P0-4 → P1-4，合计 7 raw 人日（缓冲后 ≈10.5），约 2 周交付，保住「可验收 + 队列正确 + 每日指令 + 峰值防守」四条底线。

### 复盘视角（30 天后回看的决策依据，现在记录）

1. **P0-1 放 D1**——零埋点板块 + v1 改版红利期，基线窗口仅此一次，埋点成本 0.5~1 人日是全场最高性价比。
2. **P1-4 死线 = 指令卡 T0+7**——v1 已验证复习峰值在第 7~12 天（日 50 卡），且 v1 M1 部分落地意味着峰值时钟可能已在走；这是本路线图唯一不可顺延的排期约束。
3. **P1-1 放 W3 而非 W2**——招牌闭环依赖 P0-1（验收埋点）+ P0-2（过滤队列）+ #3 决策三个前置，W2 强上只会以砍 scope 收场；W3 时三个前置全部就绪，一次做全。
4. **P2 整池冻结至复盘后**——v1 经验是激励类功能（里程碑/streak）缺乏数据证明必要性，W5 拿到 vocabTelemetry 数据后再点菜，避免凭感觉排期。
5. **回溯触发器**：W5 复盘时若「到期清空率 <80%」→ 回溯决策 2（P1-4 是否够早）；若「新词启动率 <70%」→ 回溯 P0-2 配额口径（✅ #2 已拍板全局共享，复盘验证该决策是否合理）；若「错词再练率无从统计」→ 回溯决策 1（埋点是否 D1 落地）。
