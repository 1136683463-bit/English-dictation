## 3. 本批的实际结论

### 3.1 撤下幻影项：「316 个 A0/A1 词缺失」

它在 6 份 PRD 里被互相引用，**但全库找不到任何原始实测**。
我自己量：语法语料 **859 个独特词** vs 内置词典 **12000 词**，323 个「不在词典」的分桶结果是：

| 分类 | 数量 |
|---|---|
| 屈折形式（`is`×2028 / `books`×238 / `went`×99…）| **226** |
| 缩写（`don't` / `it's` / `let's`）| 30 |
| 比较级最高级（`taller` / `biggest`）| 10 |
| 不规则过去式（`rang` / `drank`）| 4 |
| **故意造的错形**（`goodest` / `fastly`——对比卡干扰项，**本来就该错**）| 7 |
| 人名 | 5 |
| **真正该进词典的** | **1**（`cannot`）|

**⇒ 假缺口。若照它立项，产出会是「往词典塞 226 个屈折形式」——
纯造工作，且破坏词典「只收原形」的设计。**

### 3.2 `quietly` 归口改判：**不是词汇问题**

| 项 | 实测 |
|---|---|
| 语法语料出现 | 0 次 |
| **内置词典里** | ✅ **有**（`adv. 安静地, 沉着地, 秘密地`）|
| `slowly` / `carefully` / `loudly` | ✅ 词典里也都有 |

**⇒ 性质与 `loud`/`careful` 完全相同**（形容词已教、`-ly` 形式没进例句），
而那两者已由 L58 的卡片覆盖。**归口：语法课例句补丁，不是词汇线。**

### 3.3 词汇线的真实形态：**扩展，不是补缺**

现有基础设施实测：内置词典 **12000 词** + 核心种子 **115 词** + CET 词书 3 套 +
`WordsPage` + 错词本（SM-2 句子卡）+ 遥测。

**缺口不在「词」，在「序」**——有 12000 词的查询库，但没有像语法线那样
「按难度组织、有讲解有练习」的引导式序列。

真实的词汇线候选是 Cambridge 的 171 条辨析点（121 条 `X or Y?` 型），
但它们**全部是 B1+**，而我方是 A1→A2 线。
**⇒ 立项性质是「A2→B1 辨析扩展」，是产品的下一步，不是补我方缺失。**
