## ① 竞品概述

**Murphy Essential 4th**「未核实（镜像）」：**被动最早**——U21 is done / was done、U22 is being done / has been done，紧随现在完成时（U15-20）之后；**情态家族** U29 might → U30 can/could → U31 must → **U32 should** → U33 have to；**条件句最晚**——U99（第一条件句）与 U100（非真实）压到全书末尾 U97-102 连词与从句章、关系从句（U101-102）之前。三点顺序：被动 → should → 条件句。

**BC LearnEnglish**「有原文」：**分级课程里三点全无 A1-A2**（18 主题零覆盖）；条件句、被动均压 **B1-B2**。但**参考页按难度显式分层**：should 建议用法标 **Level: beginner**；未来条件从句标 **beginner**、假设用法标 intermediate，明文「条件从句不用 will」并给改正式（if it rains. NOT will rain），例外=will 表「愿意」；被动基础块标 **beginner**。即 BC 认为三点**基础规则都 beginner 可懂**，是分级课程把整点后置。

**Duolingo**「未核实（存档原文）」：**should 最早**——单元 12「不定式、祈使与情态」开篇例句即含 *He should go there*；**被动中段**——单元 31 专章；**条件句中后**——单元 43，tips 明言「从句不用将来、改用一般现在时」，且称此点为「多数母语者觉得意外」的规则。顺序同 Murphy。

## ③ 定位分析

「零术语 S5 入门」仍是空位，但**三点空位强度不同**：

- **should**：空位最浅——三源共识放情态家族前排。这不是抢跑，是补正常顺序；我方 can/must 家族（L14/L16）已把台阶铺好。
- **条件句**：空位最深——跨源后置最狠，但 BC 参考页与 Duo tips 都自认「规则本身 beginner 可懂、只是反直觉」。中文侧实证：问题不是教早了，而是**只给口诀不给理解**（「主将从现」高赞评论）。零术语给「为什么」正打这个缺口。
- **被动**：空位存在但切入成本最高——分级体系给 B1-B2 的依据不是形态（Murphy 放 U21 证明形态可早），而是**语用动机**（何时宁愿不说是谁做的）；中文「被」字直译是双刃。我们的连续剧能演「谁做的不重要」，但这需要一个完整增量位。

## ④ 可借鉴点与弱点

- **Murphy**：借「被动-情态-条件句」先形态后篇章的摆放直觉；弱点=条件句压书末最易弃学、无闭环——我们把「书末才敢教的」提前到 A2。
- **BC**：借**显式分层策略**——基础规则给 beginner、例外扩展后置（我们照抄：每点只教一型，例外不做对比卡）。
- **Duolingo**：借 should「软化建议」的功能定位、「从句不用将来」前置警示。
- **英语兔/中文侧**：借选题证明需求（口诀误区、被动场景），弱点=口诀化制造「背得出、用不对」且无回流——这些错型正是我们 contrast 卡与侦探案可直接接住的。

## ⑤ 战略建议（第六批裁决）

| 候选 | 裁决 | 依据 |
|---|---|---|
| **should** | **进**（1 课，打头） | 三源最早位；我方 L14/L16 已建家族，零新句法、一词增量；路线图 F5-B 既定「首个候选：should」 |
| **if 条件句** | **进**（限「if+现在时，主句 will」单一型） | 中文侧最大空缺；BC 参考页 future-if=beginner；以 L12 will 为桥；不碰第二/零条件句、unless、when/if 对照 |
| **被动入门** | **不进本批**（降级后置） | 真实门槛是语用动机而非形态；分词需从 have-done 块升级为可独立使用的第三形式，撞 verb_form 监控红线；灯塔 G4 留作下批锚点 |

**课量**：**4 课（L47-L50）**（析客最终拍板 3 课——收口合并，见 PRD §2.1）。L47 should → L48 if 本体 → L49 if 错型专项/收口。**顺序依据**：一课一增量红线拆课；三源一致 should 先于条件句。

**提前 A2 的风险与回报**：条件句——风险=跨源后置预期「这是难的东西」，需用零术语+一句「为什么」消解；回报=接住中文侧最大混淆面（口诀背了不懂）。被动——不进即无风险。

**工程接口提示**：灯塔终章 runes.ts 已含三点的 oneLineRule（「钥匙不同门的分量不同」「主语退到幕后」「if 的路面用现在时铺」）；第六批主课若采用相同比喻，需按 P0 同规格先核话术一致性，避免旧断言冲突。
