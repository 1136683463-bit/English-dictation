## 📌 TL;DR

1. **裁决：调整档 · 有条件放行。** 五项标准中 3 项达标（practice、output、认知层级）、1 项不可测（有效认知时长）、1 项未达标（遥测健康）。两项偏差的根因均为**遥测口径与编排缺位**，而非六段式教学内容方向问题，故不阻塞内容生产，但需绑定验证。
2. **时长判定独立实锤了口径污染**：L13 第二遍完课 `durationMs=55s` 但活动墙钟 376s（**丢失 321s**）；L16 完课 `durationMs=31s` 但墙钟 415s（**丢失 384s**）。L17 的 216.2s 是截断后的下界、且当时⑥破段不在主流程（60–110s 预算缺席）——**现有数据无法证明也未证伪 ≥6min，判定为不可测**。
3. **发现初判口径污染一处**：初判 practice 一次通过 86.1% 系把旧模板复习轮与六段式首玩混算（四份导出为累计快照，全期混算恰为 86.4%）；按六段式首玩净口径为 **79.2%**（剔除废弃半程为 85.0%），仍落在 70–85% 达标带内，结论方向不变但数字应正式更正。
4. **有条件放行方案**：不专门复测 L17。第二批（L21–L24）上线后，用其**首玩真实遥测**顺带验证两项悬置标准：有效认知时长 ≥6min（破段已入主流程 + 无 HMR 干扰）与遥测健康（双发清零、`durationMs` 不截断、`hunt_case_settled` 出现、`sectionBreakdown` 字段落地）。
5. **止损触发器（写入放行条件）**：若 L21–L24 首玩（≥2 课、无 HMR 会话）有效认知时长中位数 <4.5min，或 practice >92%（重回零摩擦），则 D1 回落止损档，暂停模板大改方向复盘。

### 1.4 认知层级覆盖（标准④）

六段式首玩会话分段覆盖：L13 五段（pretest/watch/guided/recall/practice/output 全链）、L15（pretest/watch/guided/recall/practice/output）、L16 全六段、L17 全六段（含 recall）。每课覆盖 **≥5 个 section、≥4 个认知层级**（识别→理解→提取→练习→产出），且 output 均含 ≥2 题（无提示 + hint 档）。**达标。**

## §3 正式裁决：调整档 · 有条件放行

**裁决内容**：
1. 六段式模板**内容方向成立**，放行进入 20 课补字段（R14–R18）与第二批课程制作。
2. 两项偏差（时长、遥测健康）**不要求专门复测 L17**（用户已拒绝再玩），偏差修复动作（破段入主流程、R22 双发修复、R19 侦探结算）视为已完成待验证。
3. **时长验证绑定第二批**：L21–L24 上线后，取其**首玩**（区分复习轮，参照本裁决口径）遥测顺带复核标准①⑤。

**放行条件（全部满足才算 D1 收口）**：
- [ ] L21–L24 至少 2 课产生**无 HMR 干扰、破段在主流程**的首玩完课数据；
- [ ] 首玩有效认知时长中位数 ≥360s（用修复后口径；若 `sectionBreakdown` 已落地，按分段求和核算）；
- [ ] 同批数据中 started 双发 = 0、durationMs 与墙钟差 <5s、`hunt_case_settled` ≥1、`sectionBreakdown` 字段出现；
- [ ] practice 首玩一次通过率仍落在 70–85%（观察项，不阻塞）。

**止损触发器（绑定验证期生效）**：
- 首玩有效认知时长中位数 <4.5min（270s）→ 回落止损档：保留折叠卡主线，暂停模板大改，重估方向；
- practice >92% → 零摩擦回潮，practice 摩擦方案（干扰项/变式）重做；
- output 无提示首题通过率 >70% 或 =0 → 意图锚/阶梯提示参数重校。
