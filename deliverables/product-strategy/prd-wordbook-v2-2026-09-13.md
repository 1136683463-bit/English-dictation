## 一、产品目标

北极星沿用「**每周有效学习日数 ≥5/7**」（computeStreakStats 已上线，口径干净）。三个目标正交：

- **G1 练习队列只出「该学的词」**：unit 拼写/复习队列按记忆状态过滤——新词 ≤10/日、到期词优先、mastered 默认不入场。衡量：unit 会话中 mastered 词占比 → 0；新词启动率 ≥70%（v1 延续）。
- **G2 学习动线闭环无断点**：书架有每日唯一指令（今天学哪本/学多少/多久）；从任何入口进入学习，完成/退出后回到来源页。衡量：到期清空率 ≥80%（v1 延续）；多本连学场景返回跳步 ≤1 次。
- **G3 错词沉淀为可复练资产**：错词→错因标签→生成针对性训练（动态词书）→掌握自动退出，打通错词本↔词书两容器。衡量（埋点就绪后）：错词再练率、错词书完成率。

## 二、用户故事

1. **连学者老周**：早上连续学《高频核心》《六级必备》两本书——期望学完第一本后回到书架（而不是被扔回「今日」页再绕一次），直接开第二本。
2. **控量学习者阿岚**：坚持「每天新词 ≤10」——期望点开某本词书拼写时，队列里是「新词 10 + 到期 N」，而不是把 50 个已掌握词再刷一遍。
3. **晨间学习者老周**（v1 遗留）：不想自己挑词书——期望书架顶部直接告诉他「今天：学《高频核心 23 词》新词 10 + 复习 40，约 18 分钟」。
4. **复盘型大鹏**（v1 遗留）：看到某书正确率 48%——期望点「薄弱词」直接下钻列表并一键错题拼写，而不是只看数字。
5. **材料驱动学习者小满**：听写文章攒了一批错词——期望错词自动（或一键）聚成「我的错词书」，带错因标签针对性重练，连续全对后自动毕业退出。

## 四、竞品对比（来自竞析，7 款产品）

五个差异化机会，本轮采纳排序：

1. **错词回流「听写原生」闭环**（竞析 1）：错词→错因标签→针对性训练卡→掌握自动退出。我方有 MistakeGeneration AI 能力，全市场无此颗粒度——**本轮 P1 核心新项**，做成招牌。
2. **句子级词书 / 语境网络**（竞析 2）：「词↔句↔材料」三层跳转，语境来自用户自己的材料。愿景级方向，本轮不进需求池正文，列 Non-goals（本轮不落地）。
3. **自建词书「材料驱动」路径**（竞析 3）：导入字幕/文章→听写→错词自动成书；「我的错词书」「本周材料生词书」做成一等公民动态词书——与机会 1 合并为 P1-3。
4. **三级掌握度**（竞析 4）：认得/会拼/会用显式区分。与 #2 队列过滤的 status 口径相关，作为其验收口径的一部分，不单独立项。
5. **内置精选词书**（竞析 5，防守型）：四级/六级/考研高频解决冷启动空词库——补短板项，P2。

## 七、关键流程

**流程 A：unit 学习队列（P0-2，自上而下组装）**
```
进入 /spelling?unit=X
  → 到期词（due≤now，按到期时间升序）
  → 不足 limit 用今日新词补足（全书新词日配额 ≤10，跨 unit 共享）
  → 均为空 → 空态：「本书今日无任务」（引导全量复刷入口 / 回书架）
mastered：默认不入队；详情页提供「全量复刷」手动入口（含 mastered）
```

**流程 B：学习动线闭环（P0-3 + P0-4）**
```
书架指令卡/封面卡 → 拼写会话（带来源标记 from=/units）
  → 完成页：主按钮「回到书架」（来源页），次按钮「继续下一本」（指令卡给下一对象）
  → 中途退出：回到来源页，保留分组展开/滚动位置
```

**流程 C：错词回流（P1-1）**
```
听写错词 → 错词本（MistakeGeneration 错因标签）
  → [生成词书] → 动态错词书（书架一等公民，徽标「错词」）
  → 针对该书拼写/复习（走 P0-2 队列）
  → 单词连续全对 → 自动移出错词书 + 错词本标记已掌握
  → 错词书清空 → 归档 + 庆祝态
```

**流程 D：复盘→行动（P0-5，v1 流程 C 延续）**
```
详情弹窗 正确率/薄弱词计数 → 点击 → 薄弱词列表
  → [一键错题拼写] → /spelling?unit=X&mode=mistakes（已支持）
```
