## ① 竞品概述

**Murphy Essential（剑桥初级英语语法中文版）**：目录证据（第三方 OCR，未核实）：**U21「is done / was done（被动语态1）」、U22「is being done / has been done」**——入门被动首单元只教一般现在/过去两型，进行与完成被动排在第二单元。被动紧随现在完成时 U15-20 之后，与上批结论吻合。形态=形式驱动、按型推进。

## ③ 定位分析

**「零术语 + 语用动机（谁做的不重要）」在中文侧成立明确空位**：头部内容（英语兔 105 万播放）只教构成不教场景（评论追问+UP 承认）；中文资源把"何时用"写成应试规则而非叙事。英文侧动机讲解存在但**晚到 B1-B2**（BC）或形式驱动（Murphy）。我方切入点：把「谁做的不重要」做进小美剧情，接"做过版"资产仅一步——**be + 做过版**。风险边界：不能造成"被动比主动高级"的错觉。

## ④ 可借鉴点与弱点

**借鉴**：① BC 一句式规则"只变 be、过去分词不变"——与我方零术语同构；② BC 三条动机可转译为剧情；③ ELL 三选一显示"is done vs has been done vs was done"是真实最高频困惑——练习需显式给边界；④ "汉语无主句→英语被动"与"该用不敢用"双向负迁移提示。

**弱点**：① 中文侧全家缺语用场景，且把被动等同「被字句」；② Murphy 按型罗列、动机缺位；③ BC beginner 不给动机——照抄会留下"被动为什么存在"的悬空。

## ⑤ 战略建议

**课量：2 课（主推）；容量紧张时保第 1 课。**
- **L50《被做过的事》**：is done / was done 认读 + 动机①（不知道谁做/不重要）。开场回收 L21-24 做过版，双句对照（Someone stole it. / It was stolen.）。
- **L51《谁做的不重要》**：收口（析客最终拍板 2 课：本体+收口；has been done 与 by 均不进——主理人裁决）。

**类型边界**：进 is done / was done；**has been done、by 施动者、is being done、will be done、get-passive 不进**（主理人裁决：by 是全新教学面 0 先例；been 已占「去过」义）。

**顺序**：L50 开场即回收 watched/done → 剧情事件（东西被做过）→ be + 做过版 → 动机 → 主动/被动双说法对照。Murphy"完成时之后接被动"与我方资产顺序一致。

**one-step 替代评估（否决前置）**：「先教主动避让（It is said / People say）」**不前置**——① It is said 本身就是 be+过去分词实例，绕不开；② People say 是修辞替代而非语法本体；③ 做过版资产使 be+做过版 处于最近发展区。但吸收其精神：课内保留"也可以说 People say"弹性对照。

**中文「被」字策略**：不做「被=被动」翻译训练；用受事视角叙事，同时防两端——该用不用（少用常态）与过度使用（被字直译）。
