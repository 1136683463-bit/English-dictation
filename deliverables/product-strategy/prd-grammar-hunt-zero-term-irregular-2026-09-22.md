## 1. 修复一：找错案件侧的零术语泄漏（313 → 0）

`huntCases` 的 `errors[].explanation` 是**破案反馈里直接显示给用户的**（`GrammarHuntPage.tsx`）。它与 `title`/`scene` 一起，从来不在任何零术语断言的范围里。

实测命中 **313 处 / 131 案**：

| 术语 | 处数 | 例 |
|---|---|---|
| 复数 | 107 | `three 后面是可数名词复数：three boxes。` |
| 可数 | 98 | `advice 是不可数名词，不能用 many 修饰。` |
| 三单 | 33 | `主语 She 是三单，go 要变 goes。` |
| 主语 | 32 | `主语 My brother 是三单，eat 要加 -s。` |
| 单数 / 原形 / 形容词 / 最高级 / 时态 / 第三人称 / 比较级 / 疑问句 / 否定句 / 语序 / 副词 | 各 1–9 | 见数据 diff |

**这比课程侧历史上任何一次泄漏都多**（课程侧最严重的一次是 74/102 课、680 处，但那是逐字段枚举漏网；这次是**整个文件从未被纳入守门**）。

### 1.2 修法

三轮替换、共 268 处（部分规则叠加命中），全部按「用户看得懂的画面」改写而非机械替换：

| 旧 | 新 |

| 可数名词复数 | 一群东西 / 是一群，要加 s |
| 三单 | 「他/她」一个 |
| 主语 | 句首那个「谁」 |
| 原形 | 穿回原样 / 原来的样子 |
| 时态 | 前后一致 |
| 形容词 | 「怎么样」的词 |
| 副词 | 「怎么做」的词 |
| 最高级 / 比较级 | 「最…的那个」/「更…」 |
| 疑问句 / 否定句 | 问的时候 / 说「没有」的时候 |
| 语序 | 说法 |

**修后复检：0 处。**

## 2. 修复二：L197 的「欠条」

## 4. 内容：L198 / L199

### 4.1 裁定：采纳竞析的 2 课方案，拒绝瑞思的 4 课方案

两位研究结论不同：

| 来源 | 方案 | 组织依据 |
|---|---|---|
| 瑞思 | **4 课**（按变化模式：i→a / ee→e / -tch→-aught）| 「7 个词分 4 种变化，每课 2 点 = 最少 4 课」 |
| 竞析 | **2 课**（`swim`+`sing` / `sit`+`catch`）| 中文侧按**三态同形**（AAA/ABB/ABC）分，不按元音族分 |

**裁定：采纳竞析**。理由是它给出了**跨源证据**：中文侧 10/10 条教辅标题含「归类记忆表」且按 `AAA型/ABA型` 分；而**「i→a 元音族」这种组织方式没有任何源支持**——瑞思的 4 课方案建立在一个**无跨源依据的自创分组**上。

竞析同时修正了自己的过度推断，这点值得记录。

### 4.2 L198 `swim` + `sing`（2 个新点）

- **targetSentence**：`We swam in the water and sang together.`（8 词，scene `ocean`——呼应 L190 的学游泳）
- **核心增量**：两个词的 i 都换成 a，尾巴不加 -ed
- **3 条带标记错句**：`swimmed`/`singed`（不加 -ed）· 前后不一致（`swam … sing`）· 缺 `the`
- **3 条双正解**：对照 L14 的 `I can swim.`（can 后面穿原样，不换零件）、L10 的 `went`（同一批）、L13 的 `I am swimming.`（正在 vs 做过）

### 4.3 L199 `sit` + `catch`（2 个新点）

- **targetSentence**：`I sat next to her and caught the bus.`（9 词，scene `train`——`next to` 需要并排坐的场景）
- **核心增量**：**两种换法**——`sit → sat` 是换里面的元音；`catch → caught` 是整个换成 `-aught`、那个 `gh` 不发音
- **3 条带标记错句**：`sitted`/`catched` · 前后不一致 · 缺 `the`
- **3 条双正解**：对照 L79 的 `next to`（位置 vs 动作）、L10 的 `went`、L173 的 `in order to catch`（还没赶上 vs 赶上了）
