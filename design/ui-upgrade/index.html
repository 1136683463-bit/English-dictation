UI Upgrade Proposal

让全站都用同一套语言

冒险板块已经验证了一套克制、排版主导、通栏 Hero 起首的设计语言。本方案把它抽象为可复用的令牌与组件，逐一落地到其余 8 个板块——不推翻结构，只统一口径。

8 个板块8 类核心组件1 套令牌3 期实施WCAG AA

01设计基因

从冒险板块的精修实现中提炼出 7 条铁律。它们是后续所有改动的判断准绳——出现分歧时，以此为准。

1
通栏 Hero 起首

每页第一屏由通栏视觉区承载「眉标 + 大标题 + 定位 + 主行动」，底部以渐变融入页面底色，绝不出现硬边。

2
扁平化区块

区块直接置于页面背景上。白卡只用于必须框住的一组同类信息（列表、表单），禁止卡套卡。

3
眉标系统

所有区块统一 11px / 700 / 0.14em / uppercase 小标签；主区块用橙色，次级区块用灰色。

4
排版主导层级

用 32 → 22 → 17 → 15 → 13 → 12 的字号阶梯加字重与留白建立层级，而不是靠色块和边框堆叠。

5
圆形语义图标

40px 圆形，浅 tint 底配同色系加深前景。一个模块只允许出现一个语义色，全页不超过三个。

6
胶囊控件

按钮与 chips 全部胶囊化；多选一统一为「灰底分段控件 + 白底选中块 + 橙色内描边」。

7
克制动效

hover 上浮 2px 加深投影，active 缩到 0.97，统一 140–180ms。始终尊重减少动效偏好。

✓
基准不可动

冒险板块是本方案的对齐基准。若它需要调整，先改规范，再同步到各页，避免基准漂移。

02设计令牌

04逐板块精修方案

按优先级排列。P0 是视觉割裂最严重的四页，也是投入产出比最高的；P2 只需组件口径对齐。

今日 · TodayPage

P0 优先
  • 标题裸在灰底上，与下方大卡形成"两层页头"，视觉重心混乱
  • 大卡内左侧橙色进度环 + 右侧三张白卡，两套层级并置
  • 任务队列四条各带彩色底（橙／粉／紫／蓝），是全站杂色最重的一屏
  • 页面底部还有一大块橙色 CTA，重复了上方的主行动
精修后结构
  1. PageHero 素色：NEXT BEST ACTION / 今天先清到期复习 / 定位 + 右侧主按钮与错词本
  2. 今日任务队列：区块头 + 一个面板内四条列表行，首条为进行中态；尾部数值右对齐
  3. 数据条：三个「标签 + 30px 大数字」无边框数据列，替代三张白卡
  4. 最近错误：区块头 + 统一空状态模板
  5. 底部橙色 CTA 删除，主行动已上提到 Hero
现状

页头、大卡、彩色任务行三套层级争夺注意力，主行动同时出现在 Hero 与页脚。

精修后

一个 Hero 定调，其余全部退为"信息 + 一行动作"，注意力只落在唯一的开始按钮上。

训练 · TrainingPage

P0 优先
  • 已有眉标雏形，但 Hero 与"今日训练"卡仍有两层页头感
  • 八张训练卡全白且图标是彩色方块（非圆形），密度高又没有视觉引导
  • "推荐节奏"三卡与上文风格脱节，图标又是另一种配色
精修后结构
  1. PageHero 素色：TRAINING / 选择今天的训练方式 / 右侧"回到今日"
  2. 今日训练面板：左标题与耗时，右三个无边框数据列 + 主按钮，去掉卡中卡
  3. 训练方式：八条列表行（两列），圆形语义图标，语义色收敛到四色
  4. 推荐节奏：改为无面板的编号步骤（序号橙色 28px）

词书 · UnitsPage

P0 优先
  • 全站视觉最"重"的一屏：封面用满色橙／青渐变，饱和度远高于全站基调
  • 目标进度区与下方卡片的密度、字号不同步
  • 分组标题的彩色竖条与眉标系统重复表达同一件事

问题

满色封面在冷灰页面上形成大面积高饱和色块，把注意力从"要不要开始学"抢到了"颜色好不好看"。

解法

纸面白底 + 3px 橙色书脊 + 墨色书名。识别书仍然是书，但视觉重量降到与全站同一水平。

设置 · SettingsPage

P0 优先
  • 同屏出现黄告警条 + 绿提示条 + 橙色按钮 + 蓝绿粉图标块，颜色数严重超标
  • 左右两列都是同权重白卡，分组标题层级弱，整体像后台管理页
  • 危险区、云同步等区域的样式语言与其他页不统一
精修后结构
  1. PageHero 素色：SETTINGS / 设置与导出 / 右侧"已保存"用 quiet 态而非橙色按钮
  2. 备份提醒：全页仅保留一条反馈条（琥珀），操作用 ghost
  3. 四组设置：区块头 + 面板，去掉卡套卡；数值说明改无底色小字
  4. 危险区：面板 + 红色浅描边，按钮用 danger 型
  5. 色彩收敛到两种：橙（主）与琥珀（提醒），其余全部中性

词库 · LibraryPage

P1

  • 左右分栏的详情面板与列表面板同为白卡，缺少层级差
精修后结构
  1. PageHero 素色：LIBRARY / 管理你的个人语料库 / 右侧"设置与导出"
  2. 数据条：五个无边框数据列，替代五张大白卡
  3. 轻量入口行：图标 + 文字 + 计数，透明底，hover 才出底色
  4. 工作区：左列表面板 + 右详情面板同规格；左列当前项用 3px 橙色态条

错词本 · MistakeBookPage

P1
  • 空状态全站最弱：虚线框里一段灰字，缺少引导与情绪
  • 有数据态下日期徽标颜色过多，双面板缺少主次
精修后结构
  1. PageHero 素色：MISTAKE BOOK / 错词本 / 右侧"去训练"
  2. 空状态：套用统一模板，并把"如何产生错词"拆成三步提示
  3. 有数据：左日期列表（当前日期橙色态条）右错词详情；徽标统一为中性灰加一个橙色强调

统计 · StatsPage

P1
  • 绿色健康度圆环、三色图标块与蓝紫渐变卡并存，色彩数量超标
  • 风险分层卡与今日计划步骤卡，与训练页各自为政
精修后结构
  1. PageHero 素色：WEEKLY REPORT / 学习周报 / 右侧"清到期复习"
  2. 简报面板：左标题与动作，右「健康度 40」大数字；粗圆环改为细弧
  3. 数据条：三个无边框数据列（今日收尾／错词专项／下周负载）
  4. 风险分层：列表行 + 统一琥珀图标
  5. 今日计划：编号步骤，与训练页共用同一组件
  6. 底部渐变彩卡改无边框数据列栅格

添加 · AddPage

P2 收尾
  • 全站唯一把 Hero 做成整块大白卡的页面，与冒险的通栏 Hero 直接冲突
  • 入口卡片图标为浅底方块，与圆形图标规范不一致
精修后结构
  1. PageHero 素色（不再包白卡）：ADD / 把今天遇到的材料放进来 / 右侧"导入一段材料"
  2. 采集入口：四条列表行，圆形图标 + 右侧计数与箭头
  3. 建议顺序：编号步骤，去掉橙色方块底，复用统一组件

05实施路线

建议在现有样式文件里新增一层 ui-* 通用类，与冒险板块的 adv-* 并行；每替换完一页就删掉该页旧样式，避免长期存在第三套命名。

Phase 1 · 基础 令牌与通用组件

补齐文字级语义色与间距／阴影／圆角令牌，落地 PageHero、Surface、ListRow、IconBadge、按钮五件套。

  • 不动任何业务逻辑
  • 可独立验证
Phase 2 · 高价值 今日 · 训练 · 设置 · 词书

把视觉割裂最严重的四页归位，这四页占总割裂感的大部分。

  • 今日与训练共用组件
  • 设置页色彩收敛
  • 词书封面降饱和
Phase 3 · 收尾 词库 · 错词本 · 统计 · 添加

剩余四页按规范对齐，全站达成一套语言。

  • 统一空状态
  • 统一编号步骤
  • 清理死代码
落地顺序建议：先做「今日」一页作为样板，跑通令牌与组件后横向复制到训练／统计／添加（这三页结构相近，可复用同一套 PageHero 与编号步骤）。词书与设置单独处理，因为它们各自包含一块需要重新设计的区域。

06验收清单

每页改完对照自检，全部通过才算完成。

  • 页面顶部为 PageHero，主标题 32px／700，眉标 11px uppercase，行动区不超过两个按钮
  • 区块直接置于页面背景，无卡套卡；全页视觉重量级面板不超过一个
  • 图标全部为圆形 IconBadge，图标前景使用 -ink 系列
  • 全页语义色不超过三种；所有小号彩色文字对比度不低于 4.5:1
  • 圆角只出现五档，阴影只出现四档，没有临时值
  • 多选一控件为分段控件；按钮只用 primary／ghost／quiet／danger 四型
  • 空状态使用统一模板
  • 键盘 Tab 可达全部交互元素，聚焦环可见
  • 系统开启减少动效时降级正常
  • 1440／1024／720／420 四个断点无溢出、无错位
三条注意事项：一、不要改冒险板块，它是基准；二、样式文件已超过一万四千行，先建通用层再统一清死代码，不要边改边删；三、词书封面降饱和是观感变化最大的一项，建议先出单页对比再推广。
